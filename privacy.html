Privacy policy

CS/cut is a personal tool used only by the owner of the CS/cut YouTube channel.

  • It uses the YouTube Data API solely to upload videos to the owner's own channel, set their thumbnails and add them to the owner's playlists.
  • It does not collect, store, share or sell any data about other users.
  • The OAuth token is stored only on the owner's computer and can be revoked at any time at myaccount.google.com/permissions.

CS/cut's use of information received from Google APIs adheres to the Google API Services User Data Policy.
